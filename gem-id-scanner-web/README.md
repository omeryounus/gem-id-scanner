# Gem ID Scanner for web

This package is the web client. It is not started.

Another agent should implement it from [AGENT_PROMPT.md](AGENT_PROMPT.md). That prompt is the product spec: gemstones, gallery, records, and analysis detail for scans that started on iOS, Android, or the web.

The client talks to [the backend API](../gem-id-scanner-backend/openapi.yaml). It does not embed a Gemini API key.
